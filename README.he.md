## למה

כשמדביקים `מחיר: 100$` בצ'אט או בבסיס קוד עם כיוון משמאל לימין, החלקים קופצים: נקודותיים נופלות בצד הלא נכון, סימן ה-`$` מתהפך סביב המספר, מילים לטיניות מתפזרות, ופריסות שלמות עלולות להשתקף בצורה שגויה.

הפתרון הנפוץ — היפוך פיזי של המחרוזת — מקלקל אותה לנצח: חיפוש, העתקה־הדבקה, קוראי מסך ומסדי נתונים — הכול נשבר. **הכיוון הוא מאפיין של התצוגה, לא של סדר התווים.** התוסף הזה מלמד את סוכן ה-ZCode שלכם ליישם אותו נכון, בהתאם למדיום.

## מה היא עושה

| היעד | המנגנון שהסוכן מיישם |
|---|---|
| טקסט פשוט (צ'אט, מחרוזות, קבצי טקסט) | תווי בקרה בלתי־נראים של יוניקוד: מבודדים `RLI`/`LRI` וסימנים `RLM`/`LRM` |
| HTML | ‏`dir="rtl"`, ‏`dir="auto"` ו-`<bdi>` על הקונטיינרים הנכונים |
| CSS | ‏`direction: rtl` עם **מאפיינים לוגיים** (`margin-inline-start` במקום `margin-left`…) |
| קוד ממשק משתמש (React/Vue/…) | גזירת `dir` מהשפה הפעילה (ar, he, fa, ur ← rtl) |
| Word / DOCX | ‏`<w:bidi/>` לכיוון פסקה, ‏`<w:bidiVisual/>` לטבלאות |

התוסף גם מבצע ביקורת על החלקים הקלים לפספוס: אייקונים וחצים כיווניים, צללים, גרדיאנטים, פסי התקדמות, אנימציות, פיסוק בקצה שורה, ורצפים לטיניים־מספריים מעורבבים בתוך טקסט עברי.

## התקנה

### שיטה 1 — הוספת המאגר כשוק תוספים (מומלץ)

1. פתחו **Plugin Marketplace ← Add ← Add Plugin Marketplace**.
2. הדביקו את כתובת המאגר:

   ```
   https://github.com/saboorsarem/zcode-rtl
   ```

3. פתחו **Personal ← saboorsarem-zcode-plugins ← RTL Direction ← Install**.
4. אפשר לנהל אותה בכל עת דרך **Settings ← Plugins**.

> אם הגרסה שלכם לא מקבלת כתובת GitHub כמקור שוק, שכפלו את המאגר מקומית והוסיפו את התיקייה — ראו שיטה 2.

### שיטה 2 — תיקייה מקומית

```bash
git clone https://github.com/saboorsarem/zcode-rtl.git
```

ואז פתחו **Plugin Marketplace ← Add ← Add Plugin Marketplace** והדביקו את הנתיב לתיקיית `zcode-rtl` המשוכפלת (בתוכה קובץ `.claude-plugin/marketplace.json`).

## שימוש

**פקודת סלאש** — החלת כיוון RTL על כל דבר בצעד אחד:

```
/rtl הפוך את הדף הזה לכיוון מימין לשמאל לעברית
/rtl מחיר: 100$
/rtl את הקובץ הזה components/pricing-card.tsx
```

**מיומנות אוטומטית** — פשוט בקשו; הסוכן בוחר את המנגנון לפי היעד:

```
גרמו לשורת החשבון הזאת להיות מוצגת נכון בצ'אט: חשבון: 2500 ש״ח
הוסיפו תמיכה בעברית לדף הזה ושקפו את הפריסה
```

## דוגמה

טקסט שהוקלד בצ'אט LTR:

```
מחיר: 100$
```

הסוכן מחזיר את אותם התווים עטופים במבודד RTL:

```
⁧מחיר: 100$⁩
```

בייט־בייט: `U+2067` (RLI) לפני הטקסט ו-`U+2069` (PDI) אחריו. המבודד גורם לשורה כולה להסדר כיחידה אחת מימין לשמאל בכל סביבה: המחיר בקצה הימני, הנקודותיים משמאלו, ו-`100$` נשאר קריא משמאל לימין. שום תו לא הוחלף בתוך המחרוזת — ולכן חיפוש והעתקה ממשיכים לעבוד.

### דגימות בדיקה בעברית

גרסה גולמית (בצ'אט LTR היא מתפרקת):

```
זהו טקסט בדיקה בעברית!
הפרויקט נכתב עם React גרסה 2.1.0.
מחיר סופי: 100$ (הנחה 20%)
טלפון: 03-1234567
אתר: https://example.com
```

הגרסה המתוקנת (RLI סביב כל שורה, LRI סביב קטעי LTR — אפשר להעתיק):

```
⁧זהו טקסט בדיקה בעברית!⁩
⁧הפרויקט נכתב עם React גרסה 2.1.0.⁩
⁧מחיר סופי: ⁦100$⁩ (הנחה 20%)⁩
⁧טלפון: ⁦03-1234567⁩⁩
⁧אתר: ⁦https://example.com⁩⁩
```

- סימן ה-`!` בסוף שורה 1 בלי RLI קופץ לצד הלא נכון;
- מספר הטלפון בלי LRI עלול להתקבץ מחדש (רווחים בין קבוצות ספרות הם תווים נייטרליים);
- הכתובת בשורה 5 מבודדת כדי שלא תיצמד לטקסט העברי.
