## کیوں

جب آپ `قیمت: 100$` کو بائیں سے دائیں چیٹ یا کوڈ بیس میں پیسٹ کرتے ہیں تو حصے ادھر اُدھر ہو جاتے ہیں: دونقطہ غلط سمت میں گر جاتا ہے، `$` کا نشان عدد کے گرد پلٹ جاتا ہے، لاطینی الفاظ بکھر جاتے ہیں اور پورا خاکہ بھی الٹ سکتا ہے۔

عام حل — متن کو جسمانی طور پر الٹنا — اسے ہمیشہ کے لیے خراب کر دیتا ہے: تلاش، کاپی پیسٹ، اسکرین ریڈرز اور ڈیٹا بیس سب ٹوٹ جاتے ہیں۔ **سمت نمایش کی خصوصیت ہے، حروف کی ترتیب کی نہیں۔** یہ پلگ اِن آپ کے ZCode ایجنٹ کو سکھاتا ہے کہ وہ اسے ہر ماحول کے مطابق درست طریقے سے لاگو کرے۔

## یہ کیا کرتی ہے

| ہدف | وہ طریقہ جو ایجنٹ لاگو کرتا ہے |
|---|---|
| سادہ متن (چیٹ، اسٹرنگز، ٹیکسٹ فائلز) | یونیکوڈ کے نامرئی دوطرفہ کنٹرول حروف: `RLI`/`LRI` آئسولیٹس اور `RLM`/`LRM` نشانات |
| HTML | ‏`dir="rtl"`، ‏`dir="auto"` اور `<bdi>` درست کنٹینرز پر |
| CSS | ‏`direction: rtl` کے ساتھ **منطقی خصوصیات** (`margin-inline-start` بجائے `margin-left`…) |
| ایپ UI کوڈ (React/Vue/…) | فعال زبان سے `dir` اخذ کرنا (ar، he، fa، ur ← rtl) |
| Word / DOCX | پیراگراف کی سمت کے لیے `<w:bidi/>` اور جدولوں کے لیے `<w:bidiVisual/>` |

پلگ اِن ان آسان بھولنے والی جگہوں کا بھی جائزہ لیتا ہے: آئیکنز اور سمت والے تیروں، سائے، گریڈیئنٹس، پروگریس بارز، اینیمیشنز، سطر کے آخر میں رموزِ اوقاف اور اردو متن کے اندر مخلوط لاطینی/عددی حصے۔

## انسٹالیشن

### طریقہ 1 — اس ریپوزٹری کو پلگ اِن مارکیٹ پلیس کے طور پر شامل کریں (تجویز شدہ)

1. کھولیں **Plugin Marketplace ← Add ← Add Plugin Marketplace**۔
2. ریپوزٹری کا پتہ پیسٹ کریں:

   ```
   https://github.com/saboorsarem/zcode-rtl
   ```

3. کھولیں **Personal ← saboorsarem-zcode-plugins ← RTL Direction ← Install**۔
4. اسے کبھی بھی **Settings ← Plugins** سے منظم کیا جا سکتا ہے۔

> اگر آپ کا ورژن GitHub کے پتے کو مارکیٹ سورس کے طور پر قبول نہ کرے تو ریپوزٹری کو مقامی طور پر کلون کریں اور فولڈر شامل کریں — طریقہ 2 دیکھیں۔

### طریقہ 2 — مقامی فولڈر

```bash
git clone https://github.com/saboorsarem/zcode-rtl.git
```

پھر **Plugin Marketplace ← Add ← Add Plugin Marketplace** کھولیں اور کلون شدہ `zcode-rtl` فولڈر کا راستہ پیسٹ کریں (اس میں `.claude-plugin/marketplace.json` فائل ہے)۔

## استعمال

**سلیش کمانڈ** — ایک قدم میں کسی بھی چیز پر RTL سمت لاگو کریں:

```
/rtl اس صفحے کو اردو کے لیے دائیں سے بائیں بنائیں
/rtl آخری قیمت: 100$
/rtl یہ فائل components/pricing-card.tsx
```

**خودکار سکل** — بس مانگیں؛ ایجنٹ ہدف کے مطابق طریقہ چنتا ہے:

```
یہ بل کی سطر چیٹ میں درست دکھاؤ: بل: 2500 روپے
اس لینڈنگ پیج میں اردو کی سہولت شامل کرو اور خاکہ آئینہ کرو
```

## مثال

LTR چیٹ میں لکھا گیا متن:

```
قیمت: 100$
```

ایجنٹ وہی حروف دائیں سے بائیں آئسولیٹ میں لپیٹ کر لوٹاتا ہے:

```
⁧قیمت: 100$⁩
```

بائٹ بہ بائٹ: متن سے پہلے `U+2067` (RLI) اور بعد میں `U+2069` (PDI)۔ آئسولیٹ پوری سطر کو ہر ماحول میں ایک دائیں سے بائیں اکائی کے طور پر ترتیب دیتا ہے: قیمت دائیں کنارے پر، دونقطہ اس کے بائیں، اور `100$` بائیں سے دائیں پڑھا جاتا رہتا ہے۔ اسٹرنگ کے اندر کوئی حرف نہیں پلٹا گیا، اس لیے تلاش اور کاپی کام کرتے رہتے ہیں۔

### اردو ٹیسٹ نمونے

خام ورژن (LTR چیٹ میں بکھر جاتا ہے):

```
یہ اردو میں ایک تجرباتی متن ہے!
یہ منصوبہ React ورژن 2.1.0 سے بنایا گیا ہے۔
آخری قیمت: 100$ (رعایت 20%)
رابطہ: 0300 1234567
ویب سائٹ: https://example.com
```

درست شدہ ورژن (ہر سطر کے گرد RLI، LTR حصوں کے گرد LRI — کاپی کے قابل):

```
⁧یہ اردو میں ایک تجرباتی متن ہے!⁩
⁧یہ منصوبہ React ورژن 2.1.0 سے بنایا گیا ہے۔⁩
⁧آخری قیمت: ⁦100$⁩ (رعایت 20%)⁩
⁧رابطہ: ⁦0300 1234567⁩⁩
⁧ویب سائٹ: ⁦https://example.com⁩⁩
```

- سطر 1 کے آخر میں `!` بغیر RLI کے غلط سمت میں چلا جاتا ہے؛
- فون نمبر بغیر LRI کے دوبارہ گروپ ہو سکتا ہے (ہندسوں کے گروپوں کے درمیان خالی جگہیں غیر جانبدار حروف ہیں)؛
- سطر 5 کا پتہ اردو متن سے نہ چپکے اس لیے آئسولیٹ کیا گیا ہے۔

## مطابقت
