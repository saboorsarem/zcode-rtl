## لماذا

عند لصق `السعر: 100$` في محادثة أو قاعدة برمجية باتجاه من اليسار إلى اليمين، تتقافز القطع: تهبط النقطتان في الجهة الخاطئة، وتنقلب علامة `$` حول الرقم، وتتشتت الكلمات اللاتينية المضمّنة، وقد تنعكس التنسيقات كاملةً.

والحل الشائع — قلب ترتيب الأحرف نفسه — يُفسد النص إلى الأبد: البحث والنسخ واللصق وقارئات الشاشة وقواعد البيانات كلها تنكسر. **الاتجاه خاصية عرض، وليس خاصية ترتيب الأحرف.** هذه الإضافة تعلّم وكيل ZCode لديك أن يطبّقها بشكل صحيح حسب الوسيط.

## ماذا تفعل

| الهدف | الآلية التي يطبّقها الوكيل |
|---|---|
| نص عادي (محادثة، سلاسل نصية، ملفات نصية) | رموز تحكم ثنائية الاتجاه يونيكود غير مرئية: عوازل `RLI`/`LRI` وعلامات `RLM`/`LRM` |
| HTML | ‏`dir="rtl"` و`dir="auto"` و`<bdi>` على الحاويات الصحيحة |
| CSS | ‏`direction: rtl` مع **الخصائص المنطقية** (`margin-inline-start` بدلًا من `margin-left`…) |
| كود واجهات التطبيقات (React/Vue/…) | اشتقاق `dir` من اللغة النشطة (ar، he، fa، ur ← rtl) |
| Word / DOCX | ‏`<w:bidi/>` لاتجاه الفقرات و`<w:bidiVisual/>` للجداول |

كما تدقّق الإضافة في الأجزاء سهلة الإغفال: الأيقونات والأسهم الاتجاهية، الظلال، التدرجات، أشرطة التقدّم، الحركات المتحركة، علامات الترقيم الطرفية، ومقاطع الأحرف والأرقام اللاتينية المختلطة داخل النص العربي.

## التثبيت

### الطريقة 1 — إضافة هذا المستودع كسوق إضافات (موصى بها)

1. افتح **Plugin Marketplace ← Add ← Add Plugin Marketplace**.
2. الصق رابط المستودع:

   ```
   https://github.com/saboorsarem/zcode-rtl
   ```

3. افتح **Personal ← saboorsarem-zcode-plugins ← RTL Direction ← Install**.
4. يمكنك إدارتها في أي وقت من **Settings ← Plugins**.

> إن لم يقبل إصدارك رابط GitHub كمصدر سوق، فانسخ المستودع محليًا وأضف المجلد — انظر الطريقة 2.

### الطريقة 2 — مجلد محلي

```bash
git clone https://github.com/saboorsarem/zcode-rtl.git
```

ثم افتح **Plugin Marketplace ← Add ← Add Plugin Marketplace** والصق مسار مجلد `zcode-rtl` المنسوخ (فيه ملف `.claude-plugin/marketplace.json`).

## الاستخدام

**أمر السلاش** — طبّق اتجاه RTL على أي شيء بخطوة واحدة:

```
/rtl اجعل هذه الصفحة من اليمين إلى اليسار للعربية
/rtl السعر: 100$
/rtl هذا الملف components/pricing-card.tsx
```

**المهارة التلقائية** — اطلب فقط، والوكيل يختار الآلية حسب الهدف:

```
اجعل سطر الفاتورة هذا يُعرض بشكل صحيح في المحادثة: الفاتورة: 2500 ريال
أضف الدعم للعربية إلى صفحة الهبوط هذه واعكس التنسيق
```

## مثال

نص مكتوب في محادثة باتجاه LTR:

```
السعر: 100$
```

يعيد الوكيل الأحرف نفسها مغلفة بعازل اتجاه من اليمين إلى اليسار:

```
⁧السعر: 100$⁩
```

بايت ببايت: `U+2067` (RLI) قبل النص و`U+2069` (PDI) بعده. يجعل العازل السطر كله يتوزّع كوحدة RTL واحدة في أي بيئة: السعر عند الحافة اليمنى، والنقطتان تليانه يسارًا، و`100$` يبقى مقروءًا من اليسار إلى اليمين. لم يُقلب أي حرف داخل النص، لذا يواصل البحث والنسخ العملان.

## مرجع رموز التحكم ثنائية الاتجاه

يستخدم الوكيل هذه المحارف غير المرئية — لا تظهر أبدًا كرموز مرسومة:

| الرمز | نقطة يونيكود | الاستخدام |
|------|------------|-----|
| RLM  | `U+200F` | علامة قوية باتجاه RTL بعد المحارف المحايدة (`.`, `(`, `$`) لتُحسم في الاتجاه العربي |
| LRM  | `U+200E` | علامة قوية باتجاه LTR، الحالة المقابلة |
| RLI  | `U+2067` (+ `U+2069` PDI) | عزل مقطع يجب أن يُقرأ RTL داخل سياق LTR |
| LRI  | `U+2066` (+ `U+2069` PDI) | عزل مقطع يجب أن يُقرأ LTR (روابط، كود، أرقام هواتف) داخل نص RTL |

## التوافق
