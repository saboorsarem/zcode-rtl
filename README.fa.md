## چرا

وقتی `قیمت: 100$` را در چتی چپ‌به‌راست یا پایگاه کدی می‌چسبانید، قطعه‌ها جابه‌جا می‌شوند: دونقطه در سمت اشتباه می‌افتد، علامت `$` دور عدد می‌چرخد، واژه‌های لاتین پراکنده می‌شوند و کل چیدمان ممکن است وارونه شود.

راه‌حل رایج — وارونه‌کردن فیزیکی رشته — آن را برای همیشه خراب می‌کند: جست‌وجو، کپی‌پیست، صفحه‌خوان‌ها و پایگاه‌داده‌ها همه می‌شکنند. **جهت یک ویژگی نمایش است، نه ویژگی ترتیب نویسه‌ها.** این افزونه به ایجنت ZCode شما می‌آموزد که آن را بسته به بستر، درست اعمال کند.

## چه کاری می‌کند

| هدف | سازوکاری که ایجنت اعمال می‌کند |
|---|---|
| متن ساده (چت، رشته‌ها، فایل‌های متنی) | نویسه‌های کنترلی دوجهته نامرئی یونیکود: عایق‌های `RLI`/`LRI` و نشانه‌های `RLM`/`LRM` |
| HTML | ‏`dir="rtl"`، ‏`dir="auto"` و `<bdi>` روی دربرگیرنده‌های درست |
| CSS | ‏`direction: rtl` همراه **ویژگی‌های منطقی** (`margin-inline-start` به جای `margin-left`…) |
| کد رابط کاربری (React/Vue/…) | گرفتن `dir` از زبان فعال (ar، he، fa، ur ← rtl) |
| Word / DOCX | ‏`<w:bidi/>` برای جهت پاراگراف و `<w:bidiVisual/>` برای جدول‌ها |

افزونه همچنین بخش‌های زودفراموش‌شده را بازبینی می‌کند: آیکن‌ها و پیکان‌های جهت‌دار، سایه‌ها، گرادیان‌ها، نوارهای پیشرفت، انیمیشن‌ها، نشانه‌های سطری انتهایی و رشته‌های لاتین/عددی مخلوط داخل متن فارسی.

## نصب

### روش ۱ — افزودن این مخزن به‌عنوان بازار افزونه (توصیه‌شده)

1. باز کنید **Plugin Marketplace ← Add ← Add Plugin Marketplace**.
2. نشانی مخزن را بچسبانید:

   ```
   https://github.com/saboorsarem/zcode-rtl
   ```

3. باز کنید **Personal ← saboorsarem-zcode-plugins ← RTL Direction ← Install**.
4. هر زمان می‌توانید آن را از **Settings ← Plugins** مدیریت کنید.

> اگر نسخه شما نشانی GitHub را به‌عنوان منبع بازار نمی‌پذیرد، مخزن را محلی کلون کنید و پوشه را اضافه کنید — روش ۲ را ببینید.

### روش ۲ — پوشه محلی

```bash
git clone https://github.com/saboorsarem/zcode-rtl.git
```

سپس **Plugin Marketplace ← Add ← Add Plugin Marketplace** را باز کنید و مسیر پوشه کلون‌شده `zcode-rtl` را بچسبانید (فایل `.claude-plugin/marketplace.json` درون آن است).

## استفاده

**فرمان اسلش** — اعمال جهت RTL روی هر چیزی در یک گام:

```
/rtl این صفحه را برای فارسی راست‌به‌چپ کن
/rtl قیمت نهایی: 100$
/rtl همین فایل components/pricing-card.tsx
```

**مهارت خودکار** — فقط بخواهید؛ ایجنت سازوکار را بسته به هدف انتخاب می‌کند:

```
این سطر فاکتور را در چت درست نمایش بده: فاکتور: 2500 تومان
به این صفحه فرود پشتیبانی فارسی اضافه کن و چیدمان را آینه کن
```

## مثال

متنی که در چت LTR تایپ شده:

```
قیمت: 100$
```

ایجنت همان نویسه‌ها را با عایق راست‌به‌چپ برمی‌گرداند:

```
⁧قیمت: 100$⁩
```

بایت‌به‌بایت: `U+2067` (RLI) قبل از متن و `U+2069` (PDI) بعد از آن. عایق باعث می‌شود کل سطر در هر محیطی به‌صورت یک واحد راست‌به‌چپ چیده شود: قیمت در لبه راست، دونقطه سمت چپ آن، و `100$` همچنان خوانا از چپ به راست. هیچ نویسه‌ای داخل رشته وارونه نشده، پس جست‌وجو و کپی همچنان کار می‌کنند.

### نمونه‌های آزمایشی فارسی

نسخه خام (در چت LTR از هم می‌پاشد):

```
این یک متن آزمایشی فارسی است!
پروژه با React نسخه 2.1.0 ساخته شده است.
قیمت نهایی: 100$ (تخفیف 20%)
تماس: 0912 345 6789
سایت: https://example.com
```

نسخه اصلاح‌شده (RLI دور هر سطر، LRI دور قطعه‌های LTR — قابل کپی):

```
⁧این یک متن آزمایشی فارسی است!⁩
⁧پروژه با React نسخه 2.1.0 ساخته شده است.⁩
⁧قیمت نهایی: ⁦100$⁩ (تخفیف 20%)⁩
⁧تماس: ⁦0912 345 6789⁩⁩
⁧سایت: ⁦https://example.com⁩⁩
```

- علامت `!` در پایان سطر ۱ بدون RLI به سمت اشتباه می‌پرد؛
- شماره تلفن بدون LRI ممکن است گروه‌بندی‌اش به هم بریزد (فاصله‌های بین گروه‌های رقم، نویسه‌های خنثی‌اند)؛
- نشانی در سطر ۵ عایق‌بندی شده تا به متن فارسی نچسبد.

## سازگاری

ساخته‌شده برای فرمت افزونه‌های ZCode (‏`.zcode-plugin/plugin.json`) که از قراردادهای افزونه و بازارهای سازگار با Claude Code پیروی می‌کند. مهارت هیچ وابستگی زمان اجرا ندارد — همه چیز را خود ایجنت اعمال می‌کند.
